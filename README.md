# Zen Portfolio

A Next.js App Router portfolio for Zen, a full stack developer working with .NET, Kafka, SQL, and systems architecture.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Production build

```bash
npm run build
npm start
```

The profile image and favicon are served from `public/`. The contact form is intentionally a front-end demo and directs visitors to email instead of attempting to send data.
